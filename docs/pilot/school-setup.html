What you get

Have this ready

School name & a short code (e.g. GFA001) · route names for morning and evening · each driver’s name and phone · 3–5 parents with their phone, child’s name, class and route.

Setup — about 10 minutes

  1. Register the school at mytransport.onrender.com/register — choose an admin username and password (8+ characters, letters and numbers).
  2. Sign in as admin at mytransport.onrender.com/login.
  3. Add routes (morning / evening), then add each driver with name, phone, password and route.
  4. Add parents with their phone, child name, class and route.
  5. Day-1 dry run: driver opens the site, taps Start Tracking, allows location, and the bus appears on the map.
